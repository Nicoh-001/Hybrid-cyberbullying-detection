# 🛡️ Hybrid Cyberbullying Detection Using AI

**Beyond words. Understanding context, emotions, and sentiment to detect cyberbullying.**

Cyberbullying is not always obvious. Sarcasm, hidden hostility, emotional expressions, and context-dependent language make harmful online communication difficult to detect.

This project introduces a **Hybrid Deep Learning Framework** that combines contextual understanding, emotion recognition, and sentiment analysis to identify cyberbullying in social media text.

### 🧠 What Makes It Different?

- **RoBERTa:** Captures contextual and semantic meaning.
- **GoEmotions-RoBERTa:** Extracts 28 emotional categories.
- **Sentiment RoBERTa:** Identifies sentiment polarity.
- **Variational Autoencoder (VAE):** Learns compact contextual representations.
- **Residual Deep Neural Network:** Performs final classification.
- **Integrated Gradients:** Supports explainable predictions.
